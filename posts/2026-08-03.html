🎯 本周 Top 5

01.OpenAI 曝光下一代模型 Astra：多智能体长时协作，向美政府演示

来源：The Information（8/1）· 华尔街见闻 · 机器之心 · 路透社

8月 1 日，The Information 报道 OpenAI 正筹备暂定名为"Astra"的新模型家族——核心能力是让多个AI Agent 长期分工协作、处理持续数小时的复杂项目。Sam Altman 本周在华盛顿向政策制定者和监管机构演示，展示多Agent 协同解决高阶数学问题的能力。OpenAI 同日发布报告称该模型以约 $2,000 算力成本解决了 10 道此前未被攻克的数学难题（横跨高维几何、编码理论、群论等）。Astra 将与 Sol / Terra / Luna 并列为新模型类别，可能命名为 GPT-6 或 GPT-5.7，发布时间未定，已进入测试阶段，预计成为美国首批须经政府新框架审查的前沿模型（华尔街见闻）。

产品技术视角：从"更强的聊天机器人"到"长时程工作系统"，Astra 代表范式迁移——AI 不再只回答问题，而是承担完整工作流。GPT-5.6 API 已有多Agent 测试功能（主Agent 创建子Agent 并行执行），Astra 是其正式产品化。安全层面，OpenAI 7/20 已披露一款面向长时任务的内部模型出现"现有评估未捕捉到的行为"并一度暂停使用——长周期自主运行的可控性是核心悬念。

02.DeepSeek V4-Flash 正式版 API 公测：后训练重做，Agent 暴涨 6 倍

来源：DeepSeek 官方 API 文档（7/31）· 每日经济新闻 · IT之家 · Artificial Analysis

7 月 31 日，DeepSeek 上线 V4-Flash 正式版 API。模型结构（2840亿参数 MoE、激活 130 亿、100 万 token 上下文）与预览版完全一致，仅重做后训练——结果 DeepSWE 从 7.3分飙至 54.4 分（暴涨 6 倍），Terminal Bench 2.1 达82.7 分（逼近 Opus 4.8 的 85.0）。Artificial Analysis 智能指数 50 分，距 GPT-5.6 Luna 仅 1 分；得益于 98% 缓存命中折扣，单任务成本仍比降价80% 后的 Luna 低约 60%。同日旧版 API 端点deepseek-chat / deepseek-reasoner 正式下线，全面迁移至 V4 系列（每日经济新闻）。

产品技术视角："同一骨架、后训练翻天"是本周最让行业细思极恐的信号——意味着后训练阶段的优化空间被严重低估，堆参数不再是唯一出路。DeepSeek 同步开源 Agent 测试框架 DeepSeek Harness，正在定义"如何评估长流程 Agent"这件事本身。V4-Pro 正式版尚未发布，Flash 已经在 Pareto 前沿把成本-性能曲线拉到新位置。

03.字节 Seedance 2.5 + MiniMax H3 同日上线：视频生成进入新赛段

来源：蓝鲸新闻（8/3）· 科技狐 · 搜狐一周未来商业

7 月 31 日，字节跳动发布 Seedance 2.5（单次30 秒一镜到底、多轮延长、多模态参考扩容至 30 图+ 10 视频 + 10 音频）；同日 MiniMax 发布 H3（首个商用级开源多模态视频基座模型、最长 15 秒 2K 带双声道声音、V2V Motion Transfer、近期开放权重）。H3 定价 0.8 元/秒（同类旗舰 1/3），Seedance 2.5 API 价格涨 50% 但时长翻倍。视频模型竞争从"能不能生成"转向"能不能交付"——连贯叙事、多素材协同、剪辑级精度成为新门槛（蓝鲸新闻）。

产品技术视角：Seedance 拉长镜头做闭源平台（豆包/ 即梦 / 小云雀集成），MiniMax 放开权重做生态——两条路径的碰撞决定 AI 视频的商业模型是"平台税"还是"基础设施"。H3 若第三方能复现商用级能力，将成为产业事件而非仅社区事件。

04.腾讯混元合并 LLM 与多模态团队，成立基础模型部

来源：腾讯 TEG 内部通知（7/23）· 21 世纪经济报道 · 南方日报

7 月 23 日，腾讯正式撤销大语言模型部和多模态模型部，合并成立基础模型部，由 28 岁首席 AI 科学家姚顺雨统一负责（向TEG 总裁卢山汇报）。这是 2025 年 4 月"双轨制"运行 15 个月后的终结——语言、视觉、语音、3D 研发全部纳入统一架构。姚顺雨此前已主导 AI Lab撤销（3 月）、混元基础设施全面重建（2 月）、Hy3 开源及上线（7 月），Hy3 上线一周调用量较上代增长 68 倍（腾讯云开发者社区）。

商业战略视角：腾讯 AI 从"分散探索"全面转向"集中统筹"，姚顺雨入职 8 个月内三次重大架构调整（撤 AI Lab → 重建基础设施 → 合并团队），速度堪称激进。核心逻辑：追赶前沿需要统一算力资源分配和技术路线，多模态不能与 LLM 割裂。下一个验证点是全模态模型能否真正在游戏 / 视频 / 办公场景拉开差异化。

05.Kimi K3 权重正式开放，半小时登顶 Hugging Face 热榜

来源：Hugging Face moonshotai/Kimi-K3（7/27）· 潮新闻 · AI 大模型周报

7 月 27 日晚，月之暗面在 Hugging Face 正式发布 Kimi K3 完整模型权重（2.8T 参数 / 896路由专家/ 激活 16/ 原生视觉 / 100 万 token），同步公开技术报告及 MoonEP、FlashKDA、AgentEnv 三项训练基础设施。MXFP4 格式下仅需约 1.4TB 存储（FP16 的 1/4），8-16 节点 8×H100 即可自托管。发布半小时冲上HF 热门榜首，硅谷科技公司联署呼吁美政府不要封禁中国 AI 模型。K3 已推动月之暗面年化收入达 3亿美元，支撑 500亿美元港股IPO 估值（潮新闻）。

商业战略视角：K3 是全球首个真正逼近闭源前沿的开源权重模型，且附带完整训练栈——这不仅是模型开源，而是方法论开源。AWS / Azure / GCP 可直接托管（消除中国数据驻留顾虑），$3/M 等效API 成本使其成为最具性价比的自托管选项。对Anthropic / OpenAI 的定价权构成结构性压力。

🔍 本周三大主题

主题一：AI Agent 从"工具调用"走向"长时程自主工作"

三条线索在本周交汇：① OpenAI Astra 明确以"多Agent 长期协作"为卖点，目标是处理数小时甚至更长的工作流；② DeepSeek V4-Flash 正式版把Agent 能力作为核心升级维度（DeepSWE 暴涨 6 倍），同步开源 Agent 评测框架；③ OpenAI 此前已确认覆盖超10亿活跃用户，Codex Agent 工作占每周输出 token 的 99.8%。Agent 不再是实验室demo，而是真实生产力工具——但"长时程自主运行"的安全边界仍未形成行业共识。

趋势研判：2026 下半年的模型竞争主轴将从"单次回答质量"转向"持续可靠执行"。评价标准不再是 benchmark 分数，而是"能否稳定推进一个项目、识别中途错误、协调多个子任务"。Gartner 预计到 2026 年底 40% 企业应用将集成任务型 AI Agent（2025 年不到 5%），到 2030 年约 2340 亿美元 SaaS 支出将被Agentic AI 重塑。

主题二：视频生成模型从"demo 级"进入"交付级"

Seedance 2.5 把单次可控时长拉到 30 秒（足以组织完整叙事），MiniMax H3 首次在商用级水平放开权重（2K / 多模态输入 / 带声道）。过去一年视频模型的痛点是"每个镜头单独惊艳、剪到一起就崩"，原因是模型没有跨镜头状态记忆。Seedance 2.5 的多轮延长和H3 的 12 素材并行输入，都在试图从架构层面解决叙事连贯性。定价差异（H3 低至 0.8 元/秒 vs Seedance 涨价 50%）也暗示两种商业策略的分化。

趋势研判：AI 视频的下一轮竞争不再比"谁的镜头更长"，而是比"谁能进入真实制作流程"——带货短视频、企业培训、广告成片、短剧。H3 开源若能被第三方复现，将打破闭源平台垄断分发的规则。预计 Q3 还会有更多视频模型公布开放权重（可灵、Pika 均有暗示）。

主题三：中国开源 AI 进入"方法论开放"阶段

Kimi K3 不仅开源权重，还一并公开训练栈（MoonEP 通信库/ FlashKDA 注意力内核 / AgentEnv 环境基础设施）；DeepSeek 同步开源 Agent 评测框架 DeepSeek Harness；MiniMax 承诺数日内开放 H3 视频模型权重。加上此前 DeepSeek V4 的 MIT 协议、腾讯 Hy3 的 Apache 2.0，中国 AI 厂商在 2026 年下半年集体从"给你权重"升级到"给你整套工具链"。NVIDIA CEO 上周首帖力挺开放权重，硅谷科技公司联署反对封禁——开源正在成为地缘博弈中的战略筹码。

趋势研判：方法论开源的核心逻辑是"生态锁定"：当开发者围绕你的训练栈、评测框架、推理引擎构建工作流，即使模型本身可替换，迁移成本也已足够高。这是中国 AI 实验室从"性价比追赶者"向"标准制定者"角色转换的信号。EU AI Act 透明度要求也在客观上为开源模型创造政策红利。
